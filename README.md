Интерактивный проект, посвящённый изучению миграционных маршрутов краснокнижных морских млекопитающих.
Цель проекта — исследовать перемещения морских животных, визуализировать их миграционные пути и привлечь внимание к сохранению редких и исчезающих видов.
В основе проекта лежат данные и материалы двух международных ресурсов:
IUCN Red List(https://www.iucnredlist.org/) — сведения о природоохранном статусе видов и угрозах их существованию.
Movebank(https://www.movebank.org/cms/movebank-main) — база данных о перемещениях животных, полученных с помощью систем отслеживания.
